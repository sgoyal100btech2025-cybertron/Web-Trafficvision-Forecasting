# TrafficVision AI 🚀

AI-powered Website Traffic Forecasting Platform using:

- Flask 
- Scikit-learn
- Plotly
- Pandas
- SQLite
- Bootstrap

## Features 🔮

- AI Traffic Forecasting
- Random Forest + Linear Regression
- Interactive Analytics Dashboard
- CSV Upload
- Prediction History
- Export Forecast
- Responsive Dark UI
- AI Charts & Insights

# Installation $ SETUP:👾
 
### 1. Clone the repository
 ```bash
git clone https://github.com/YOUR-USERNAME/Website-Traffic-Forecasting.git
```

#### 2. Open the project
```bash
cd Website-Traffic-Forecasting
```
### 3. Create a virtual environment
**Windows:**
```bash
python -m venv venv
```

**Activate it:**
```bash
venv\Scripts\activate
```

**Linux/macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```
### 4. Install dependencies
```bash
pip install -r requirements.txt
```
### 5. Run the Flask application
```bash
python app.py
```
### 6. Open the application
Go to:
```bash
http://127.0.0.1:5000
```
